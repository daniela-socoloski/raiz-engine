# Visual design — canonical reference

## Foundations
- Massimo Vignelli — *The Vignelli Canon* (2010, free PDF)
- Paul Rand — *Thoughts on Design* (1947)
- Josef Müller-Brockmann — *Grid Systems in Graphic Design* (1981)
- Jan Tschichold — *The New Typography* (1928)
- Karl Gerstner — *Designing Programmes* (1964)
- Emil Ruder — *Typographie: A Manual of Design* (1967)
- Wolfgang Weingart — *My Way to Typography* (2000)

## Typography
- Robert Bringhurst — *The Elements of Typographic Style* (1992) · PT-BR: *Elementos do Estilo Tipográfico*, Cosac Naify
- Ellen Lupton — *Thinking with Type* (2004)
- Karen Cheng — *Designing Type* (2005)
- Adrian Frutiger — *The Type and the Eye* (1998)
- Hermann Zapf — *Manuale Typographicum* (1968)
- Erik Spiekermann — *Stop Stealing Sheep* (1993)
- Peter Biľak — Typotheque essays

## Note on the study set

Brand and studio names are the one part of this file worth occasionally pulling into
context — not as authority, but as *calibration targets*. "Does this read closer to
Aesop or closer to a template?" is a usable evaluation prompt. The bibliography is not:
citing Bringhurst inside a prompt does not make the output more typographically correct.
It only makes the prompt longer.
