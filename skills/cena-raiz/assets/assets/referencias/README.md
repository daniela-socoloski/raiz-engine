# referencias/

Referências visuais: estilo, paleta, prints, campanhas, frames de motion que você gosta.

Guiam **como** a arte vai parecer — recorte, textura, densidade, cor, ritmo de composição.

**Não são copiadas.** O sistema olha, entende o que faz aquilo funcionar, e escreve o prompt naquele espírito.

Duas ou três boas valem mais que dez. Referências que brigam entre si (uma minimalista, uma carregada) puxam o resultado para o meio do caminho.
