# produto/

Fotos do produto, embalagem, packshot.

Serve para o produto aparecer na imagem estática com a forma, a cor e o rótulo certos.

**Melhor resultado:** fundo limpo ou já recortado, produto de frente ou em três quartos, boa resolução.

Se o produto for crítico (rótulo legível, cor exata de embalagem), diga isso na conversa — a direção muda para proteger a fidelidade.
