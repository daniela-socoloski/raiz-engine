# logo/

O logo do cliente.

**Formato ideal:** PNG com fundo transparente.

**Este arquivo não entra na imagem estática.** Ele sobe separado para o Seedance, junto com a imagem principal, e aparece no **final do motion**.

Se você só tiver o logo em JPG com fundo branco, dá pra seguir — mas o fecho fica melhor com transparência.

Se tiver versões (positiva, negativa, monocromática), coloque todas. O sistema escolhe a que funciona sobre o fundo da arte.
